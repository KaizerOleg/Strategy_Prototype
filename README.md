# Strategy_Prototype
Tech Stack: C#, Unity, ScriptableObjects, Procedural Generation, Hex-Grid Algorithms, Unity Netcode for GameObjects.

A Civilization-inspired turn-based strategy game developed in Unity using C#. Features a hexagonal grid system, procedural terrain generation, unit movement, turn management, city development, economy systems, and data-driven gameplay architecture using ScriptableObjects. Also explores multiplayer functionality with Unity Netcode for GameObjects, including client-server communication and network state synchronization.
